# Бүлэг 13 — Монгол хэл, нэр томьёо ба соёлын загвар

> **Гол дүгнэлт**
> - **v1-д зөвхөн монгол хэл.** Гэхдээ i18n давхарга (ICU MessageFormat) ба `en` нөөц багцыг **хамгийн эхний commit-оос** эхлээд холбоод тавь. Орчуулга нь зардал биш, **арчилгаа** нь зардал.
> - **Фонтын хамгийн том алдаа:** `Ө` ба `Ү` үсэг Google Fonts-ын `cyrillic` дэд багцад **БАЙХГҮЙ**, `cyrillic-ext` дотор байдаг. `subset=cyrillic` гэж бичвэл `ШӨНӨ`, `МӨРДӨГЧ`, `ҮЗЭГЧ` гэсэн үгс эвдэрч харагдана. Шийдэл: `subset=` параметрийг **огт бичихгүй**.
> - **Дагавар үүсгэгч хөдөлгүүр бичихгүй.** Монгол хэлний эгшгийн зохицол + богино эгшиг гээгдэх үзэгдэл нь тоглогчийн нэрэн дээр алдаа гаргана (`Цэцэг` → `Цэцгийн`, хөдөлгүүр `Цэцэгийн` гэж буруу гаргана). Оронд нь **мөрийг өөрийг нь дагаваргүй болгож зохион байгуул**: `Дүр: {name}`, `{name} — хасагдлаа`.
> - **Хөтлөгчийн дуу хоолойг build үед урьдчилан рендерлэ.** Azure-ийн `mn-MN-BataaNeural` / `mn-MN-YesuiNeural` хоёр л монгол хоолой байна. Google Cloud TTS болон ElevenLabs-д монгол хэл **огт байхгүй**. Runtime-д API дуудахгүй — офлайн ажиллах, 0 мс хоцролт, 0 төгрөгийн зардал.
> - **Дэлгүүрийн хатуу хязгаар:** Google Play-д `mn-MN` жагсаалтын хэл **байдаг** (~101 хэл), харин Apple App Store-ын **50** бүтээгдэхүүний хуудасны хэлэнд монгол хэл **БАЙХГҮЙ** → iOS-ийн дэлгүүрийн тайлбар англиар байх ёстой. Апп доторх UI нь `mn.lproj`-оор монгол хэвээрээ байж болно — тэр хоёр өөр систем.
> - **Үндсэн сэдэв: «Улаанбаатар ноар».** Өсвөр насныханд хамгийн ойр, шашны эрсдэл тэг, урлагийн зардал хамгийн бага, «шөнийн радио хөтлөгч» гэсэн заль нь синтезчилсэн хоолойг өөрөө зөвтгөж өгдөг.

## 1. Албан ёсны монгол нэр томьёоны толь

Монгол хэл дээрх эх сурвалжуудаас олдсон дүгнэлт: монгол тоглогчид фракцийг нэрлэхдээ орос хэлнээс орж ирсэн **мафи / мафия** гэдэг үгийг дийлэнхдээ хэрэглэдэг, дүрүүдийн хувьд бол *иргэн, эмч, цагдаа, хулгайч, комиссар, шударга* гэсэн бага боловч тогтвортой багц монгол үгс монгол хэл дээрх тайлбаруудад **бодитоор баримтжсан** байна (mongolcom.mn, mn.unansea.com).

Онцгой анхаарах зүйл: **mn.wikipedia.org дээр Мафи ширээний тоглоомын тухай өгүүлэл огт байхгүй.** Тэгэхээр монгол хэл дээр хэвлэгдсэн албан ёсны дүрмийн ном гэж байхгүй.

**Энэ апп нь бодитоор стандарт үгсийн сан болж чадна, бас болох ёстой.** Энэ нь үгсээ маш болгоомжтой сонгож, дараа нь бүх газарт (UI, аудио, тусламж, зар сурталчилгаа) **яг ижилхэн** хэрэглэх ёстой гэсэн үг.

> **Баталгаажуулалт (2026-09-15):** «mn.wikipedia дээр Мафи ширээний тоглоомын өгүүлэл байхгүй» — **Батлагдсан.** Хайлт нь зөвхөн *Frank Costello*-г буцаадаг бөгөөд вики өөрөө уг хуудсыг үүсгэхийг санал болгож байна. Эх сурвалж: https://mn.wikipedia.org/

### 1.4 Хөтлөгчийн скрипт (үг үсгээрээ монголоор, офлайн горим)

Доорх блок бол **офлайн горимын хөтлөгчийн бүх мөр**. Зүүн талд байгаа том үсгээр бичсэн үг бол кодын дотор хэрэглэх **түлхүүр (string ID)**, баруун талд нь утсанд бичигдэж, дуугарах монгол өгүүлбэр. Түлхүүрийг хэзээ ч бүү орчуул.

```
NIGHT_START      Хот унтлаа. Бүгд нүдээ ань.
MAFIA_WAKE       Мафи сэр. Хохирогчоо сонго.
MAFIA_SLEEP      Мафи унт.
DOCTOR_WAKE      Эмч сэр. Хэнийг аврах вэ?
DOCTOR_SLEEP     Эмч унт.
DETECTIVE_WAKE   Мөрдөгч сэр. Хэнийг шалгах вэ?
DETECTIVE_SLEEP  Мөрдөгч унт.
DAY_START        Хот сэрлээ. Бүгд нүдээ нээ.
NIGHT_NO_KILL    Өнөө шөнө хохирогч гарсангүй.
NIGHT_KILL       Өнөө шөнө {N}-р тоглогч хохирлоо.
DISCUSS_START    Хэлэлцүүлэг эхэллээ.
TIME_30          Гучин секунд үлдлээ.
VOTE_START       Санал хураалт эхэллээ.
VOTE_RESULT      {N}-р тоглогч хотоос хөөгдлөө.
VOTE_TIE         Санал тэнцсэн тул хэн ч хөөгдөхгүй.
REVEAL_ROLE      Тэрээр {ROLE} байлаа.
WIN_MAFIA        Мафи ялалаа!
WIN_TOWN         Хотынхон ялалаа!
```

`{N}-р тоглогч` гэсэн загварыг анзаар: `-р` бол дэс тоог товчилж тэмдэглэх тэмдэг бөгөөд үүнийг CLDR баталгаажуулж байна (`Intl.DateTimeFormat('mn-MN',{month:'short'})` нь `1-р сар … 12-р сар` гэж буцаадаг).

**Өгүүлэмжид тоглогчийн НЭРИЙГ биш, ДУГААРЫГ нь хэл** — яагаад гэдгийг §2.4-т үзнэ үү.

## 2. Монгол хэлтэй холбоотой техникийн асуудлууд

### 2.1 Фонт — гаргахад гарах №1 алдаа

`Ө ө` = U+04E8 / U+04E9. `Ү ү` = U+04AE / U+04AF. Хоёулаа Unicode-ийн кирилл блокт байгаа боловч **Google Fonts-ын `cyrillic` дэд багцад БАЙХГҮЙ.** 2026-09-15-нд CSS API-г татаж баталгаажуулав:

Доорх блок бол Google-ийн өгдөг CSS дотор байдаг яг тэр мөрүүд. `unicode-range` гэдэг нь «энэ дэд багц ямар үсгүүдийг агуулж байна» гэсэн жагсаалт.

```
/* cyrillic     */ unicode-range: U+0301, U+0400-045F, U+0490-0491, U+04B0-04B1, U+2116;
/* cyrillic-ext */ unicode-range: U+0460-052F, U+1C80-1C8A, U+20B4, U+2DE0-2DFF, U+A640-A69F, U+FE2E-FE2F;
```

`U+04AE` ба `U+04E8` нь `U+0460-052F` муж дотор унаж байна → **зөвхөн `cyrillic-ext`**.

`?family=Inter&subset=cyrillic` гэж бичсэн хөгжүүлэгч ихэнх үгэн дээрээ зөв текст авах боловч яг `Ө` ба `Ү` дээр **өөр харагдах нөөц (fallback) glyph** авна — өөрөөр хэлбэл дэлгэц дээрх хамгийн монгол хоёр үсэг нь үсрээд харагдана. `ШӨНӨ`, `ҮЗЭГЧ`, `МӨРДӨГЧ`, `ӨДӨР` гэсэн үгс эвдэрсэн шиг харагдана.

**Засвар:** `subset=` параметрийг **огт бичихгүй** (Google бүх дэд багцыг `unicode-range`-тэй нь өгдөг бөгөөд браузер зөвхөн ашигласан хэсгийг татдаг), эсвэл `cyrillic-ext`-ийг тодорхой шаардах.

`cyrillic-ext` байгаа эсэхийг баталгаажуулсан жагсаалт (`fonts.googleapis.com/css2`-ийн эсрэг curl, 2026-09-15):

| Фонт | cyrillic-ext бий юу? | Тохиромж |
|---|---|---|
| Inter, Rubik, Manrope, Montserrat, Nunito, Onest, Golos Text, Noto Sans, Roboto Condensed, Oswald, Alegreya, Unbounded, Play, Press Start 2P | **БИЙ** (бүх **14**-ийг 2026-09-15-нд curl-ээр дахин баталгаажуулав) | Аюулгүй. `Rubik` / `Onest` / `Manrope` = өсвөр насныханд ээлтэй UI; `Oswald` = нарийн дэлгэцийн фонт; `Unbounded` = бүдүүн дэлгэцийн фонт. |
| **Russo One** | зөвхөн `cyrillic`, **ext байхгүй** | ❌ `Ө`/`Ү`-г эвдэнэ |
| **Bebas Neue** | кирилл огт байхгүй | ❌ Зөвхөн латин |

**Дурын нэр дэвшсэн фонтыг өөрөө нэг мөрөөр шалга.** Анхаар: User-Agent нь заавал **орчин үеийн браузерынх** байх ёстой, эс бөгөөс Google нь `unicode-range` блок **огт байхгүй** ганц хуучин TTV/TTF өгдөг бөгөөд grep нь бүх фонт дээр 0 буцаана:

```
curl -s -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120 Safari/537.36" \
  "https://fonts.googleapis.com/css2?family=FONT+NAME&display=swap" | grep -c cyrillic-ext
```

`Noto Sans Mongolian` (v23) нь Google Fonts дотор байгаа бөгөөд **уламжлалт босоо бичиг**-ийг (U+1800–U+18AF) хамардаг — зөвхөн лого/wordmark-д ашиглахад тохиромжтой. Монгол Улс 2020 оны 3 сарын үндэсний төлөвлөгөөний дагуу 2025 оноос босоо бичгийг кириллийн хажуугаар **хамтран албан ёсны** болгосон тул босоо бичгээр хийсэн wordmark нь соёлын хувьд цаг үеэ олсон, бас үнэтэй сайхан харагдана — **гэхдээ үндсэн UI-д бүү ашигла**; өсвөр насныхан кирилл уншдаг.

Нэмэлт фонтын шалгалт: аппаа жирийн Android ба iOS төхөөрөмж дээр ажиллуулаад `ӨҮөү` гэсэн үсгүүдийг дэлгэцийн зураг авч шалга. Системийн нөөц фонтод найдахын оронд фонтын файлыг **апп дотроо суулгаж яв**.

**[баталгаажаагүй]** iOS-ийн SF Pro фонт `Ө/Ү`-г яг хэр сайн хамардаг нь тодорхойгүй — бодит төхөөрөмж дээр рендерлэж шалгах замаар баталгаажуул.

> **Баталгаажуулалт (2026-09-15):** «`Ө/Ү` нь `cyrillic`-д биш `cyrillic-ext` (U+0460-052F)-д байдаг» — **Батлагдсан.** Яг тэр `unicode-range` мөрүүдийг `fonts.googleapis.com/css2`-оос дахин curl-дэж авсан. Мөн «Russo One = зөвхөн `cyrillic`; Bebas Neue = кирилл огт байхгүй» — **curl-ээр батлагдсан.** Эх сурвалж: https://fonts.googleapis.com/css2?family=Inter&display=swap

### 2.2 Эрэмбэлэлт — энгийн `.sort()` бол БУРУУ

Албан ёсны цагаан толгойд `Ө` нь `О`-гийн яг араас, `Ү` нь `У`-гийн яг араас ордог. Харин Unicode-ийн код цэгийн дараалал тэднийг **`я`-гийн араас** тавьдаг. 2026-09-15-нд Node v22 дээр хэмжсэн:

Доорх блокт зүүн талд нь ямар аргаар эрэмбэлснийг, баруун талд нь гарсан үр дүнг харуулав.

```
naive .sort()        : Ариун, Билгүүн, Ням, Оюун, Уянга, Эрдэнэ, Ялалт, Үнэн, Өнөр   ← буруу
Intl.Collator('mn')  : Ариун, Билгүүн, Ням, Оюун, Өнөр, Уянга, Үнэн, Эрдэнэ, Ялалт   ← зөв
```

**Дүрэм: хэрэглэгчид харагдах нэр, өрөө, тэргүүлэгчдийн жагсаалтын БҮХ мөр `new Intl.Collator('mn').compare`-ийг ашиглах ёстой.** (`Intl.Collator('ru')` санамсаргүйгээр ижил үр дүн өгдөг боловч түүнд бүү найд.)

> **Баталгаажуулалт (2026-09-15):** «энгийн `.sort()` буруу, `Intl.Collator('mn')` зөв» — **Батлагдсан**, Node v22.22.2 дээр үг үсгээрээ дахин гаргасан. Эх сурвалж: https://www.unicode.org/cldr/charts/47/collation/mn.html

### 2.3 Олон тоо, тоо, огноо — `Intl` чамд юуг үнэгүй өгөх вэ

| API | `mn-MN` гаралт | Хийх зүйл |

| `Intl.NumberFormat('mn-MN').format(1234567.89)` | `1,234,567.89` | Таслалаар бүлэглэнэ, цэгээр бутархайлна. |
| Валют `MNT` | `₮ 9,900.00` | ⚠ **`maximumFractionDigits: 0` болгож дарж бич** → `₮ 9,900`. Төгрөгийг бодит амьдрал дээр хэзээ ч аравтын оронтойгоор бичдэггүй. |

Мөн «тоо/валют/огноо/цаг/гаригийн бүх гаралт» — **Батлагдсан**, бүх мөрийг Node v22.22.2 ICU дээр үг үсгээрээ дахин гаргасан. Эх сурвалж: https://www.unicode.org/cldr/charts/47/supplemental/language_plural_rules.html

### 2.4 Залгамал бүтэц — `"{name}-ийн дүр"` яагаад алдаа вэ

Монгол хэл бол эгшгийн зохицолтой, дагавараар үг бүтээдэг хэл. Эгшгүүд дараах байдлаар хуваагдана (кирилл монгол бичгийн дүрмийн дагуу):

- **эр эгшиг**: а, о, у, я, ё, ю(у), ы
- **эм эгшиг**: э, ө, ү, е, ю(ү)
- **саармаг эгшиг**: и, й — **зөвхөн саармаг эгшигтэй үг эм дагавар авдаг**

Харьяалахын тийн ялгал (`-ийн`, «Батын дүр» гэхэд чи авах гэж хүрэх тэр дагавар) нь **дор хаяж зургаан хувилбартай**: `-ын / -ийн / -ны / -ний / -гийн / -н`. Аль нь орох вэ гэдэг нь эгшгийн ангилал **БА** төгсгөлийн үсэг **БА** нуугдмал `н` байгаа эсэхээс шалтгаална. Заахын тийн ялгал нь `-ыг / -ийг / -г`; өгөх-оршихын тийн ялгал нь `-д / -т`.

Дүрэм суурьтай туслах функцийн загварыг хийж, бодит монгол хүний нэр дээр туршив:

| Нэр | Туслах функцийн гаралт | Зөв үү? |
|---|---|---|
| Бат | Батын | ✅ |
| Сараа | Сараагийн | ✅ |
| Оюун | Оюуны | ✅ |
| Билгүүн | Билгүүний | ✅ |
| Мөнх | Мөнхийн | ✅ |
| **Цэцэг** | **Цэцэгийн** | ❌ зөв нь **Цэцгийн** — тогтворгүй богино эгшиг `э` гээгдэнэ |

Яг тэр сүүлийн мөр бол гол санаа. **Богино эгшиг гээгдэх** үзэгдэл ба нуугдмал `н`-ийн тийн ялгал гэсэн хоёр зүйл нь дагавар үүсгэгч функцийг нэрсийн мэдэгдэхүйц хувь дээр буруутгана — тэгээд тэр алдаа нь **тоглогчийн өөрийнх нь нэр дээр, найз нөхдийнх нь өмнө, амьд тоглолтын дунд** гарна. Гадаад нэр, хочууд (`xXShadowXx`, `Диана`, `бат_123`) байдлыг улам дордуулна.

**Тиймээс: дагавар үүсгэгч хөдөлгүүр огт бүү бич. Оронд нь мөрүүдээ дагавар огт шаардахгүй байхаар зохион байгуул.**

#### Мөр зохион байгуулах дүрмүүд (code review-д эдгээрийг мөрдүүл)

1. **Нэрийг тийн ялгалын дагавар шаардах байрлалд хэзээ ч бүү оруул.** Нэрийг **нэрлэхийн тийн ялгалаар**, өгүүлбэрийн эхэнд, цэг таслал эсвэл байршуулалтаар тусгаарлаж тавь.
   - ❌ `{name}-ийн дүр` → ✅ `Дүр: {name}` эсвэл `{name} — {role}`
   - ❌ `{name}-ийг аврав` → ✅ `Аврагдсан: {name}` эсвэл `{name} — аврагдлаа`
2. **Нэр үгэн дээр тийн ялгал тавихын оронд өгүүлбэрийн төгсгөлд үйл үгийн нөхцөл ашигла.** `{name} хасагдлаа.` гэсэн өгүүлбэр `{name}` дээр ямар ч дагавар шаардахгүй.
3. **Бүх статистик, үр дүнд цэгтэй шошгын загвар ашигла.** `Санал: 3`, `Ялалт: 12`, `Дүр: Эмч`.
4. **Өгүүлэмжид тоглогчийн НЭРИЙГ биш, ДУГААРЫГ хэл** — `{N}-р тоглогч` нь урьдчилан таамаглаж болохоор хувирдаг бөгөөд TTS түүнийг зөв дууддаг. Нэрийг нь дэлгэц дээр зэрэг харуул.
5. **Хэсгүүдийг хэзээ ч бүү залга.** Нэг мөр = нэг бүтэн өгүүлбэр. Орчуулагч ч, хэлзүй ч `"Тоглогч " + verb + " байна"` гэсэн зүйл дээр эвдэрнэ.
6. **Товч, тэмдэглэгээний байршуулалтад англи хувилбартай харьцуулахад текст 25–40% сунгахыг зөвшөөр.** Зарим монгол мөр илүү богино байдаг ч дүр/төлөвийн үгс нь нийлмэл үгс байдаг. Тогтмол өргөнтэй товч хэзээ ч бүү хийж болохгүй.
7. **Босоо зай:** `Ө Ү Й Ё` үсгүүд дээрээ тэмдэгтэй тул `line-height ≥ 1.35` болго, эс бөгөөс дээд хэсэг нь тасарна.
8. **Том үсэг аюулгүй ч хашгирсан сонсогдоно.** `ШӨНӨ` сайхан уншигдана; гэхдээ бага хэрэглэ, өсвөр насныхан үүнийг хашгираад байна гэж ойлгодог.
9. **Толь бичгийг машинаар бүү орчуул.** §1-ийг repo дотор `GLOSSARY.md` болгож царцаагаад, толиос гадуурх ижил утгатай үг ороогүй эсэхийг lint-ээр шалга.

#### Зөвлөмж болгох i18n стек

- **Формат: ICU MessageFormat.** Чамд `select` (дүрээс/хүйснээс хамааран өөрчлөгддөг текстэд) ба 2 ангилалтай `plural` үнэхээр хэрэгтэй. `i18next` + `i18next-icu`, эсвэл `react-intl`/FormatJS, эсвэл Flutter-ийн дотоод `.arb` + `intl` (энэ нь угаасаа ICU MessageFormat) ашигла. **Гар аргаар бүү бич.**
- **Хэлний файлууд:** `mn.json` нь үнэний эх сурвалж (монгол хэлтэй хүн бичнэ), `en.json` нь нөөц бөгөөд хожмын орчуулагчийн түшиц.
- **Түлхүүрийн нэршил:** `game.night.mafia_wake`, `lobby.button.create_room` — англи текстийг түлхүүр болгож хэзээ ч бүү хэрэглэ, учир нь монгол хувилбар нь эх хувилбар.
- **CI lint:** дараах тохиолдолд build-ийг унага: (а) `t()` дуудлагын дотор `+`-оор мөр залгасан бол, (б) хэлний файлд интерполяцын яг араас `-ийн|-ын|-ний|-ны|-ийг|-ыг|-д|-т` орсон бол. Энэ ганц regex л §2.4-ийн ихэнхийг урьдчилан сэргийлнэ.

### 3.2 Архитектурын зөвлөмж: **урьдчилан рендерл, урсгалаар бүү ав**

Хөтлөгчийн скрипт бол **тогтмол, жижиг, төгсгөлөг мөрүүдийн багц**. Runtime дээр TTS API бүү дууд.
Клип бүрийг build үед үүсгээд, `.ogg`/`.m4a` нөөц болгож апп дотор суулгаад, локалаар тогло.

Яагаад энэ нь эндээ хатуу давуу вэ: **интернэт огт шаардахгүй** ажиллана (офлайн/нүүр тулсан горимд
зайлшгүй — утас нь ангийн ширээн дээр байгаа), **хоцролт тэг** (400 мс сүлжээний саатал «Мафи сэр» гэсэн
хэмнэлийг сүйтгэнэ), **тоглолт тутмын зардал тэг**, бас чи нэг удаа шалгаад дуусгачихдаг **детерминист**
аудиотай болно.

урьдчилан рендерлэх нь бодит утгаараа үнэгүй.

⚠ **Синтезчилсэн аудиог кэшлээд аппын дотор суулгаж тараахад Azure-ийн нөхцөл юу гэж байгааг үүнд
найдахаасаа өмнө шалга.** Azure TTS-ийн ил тод байдлын тэмдэглэл (transparency note) болон бүтээгдэхүүний
нөхцөл нь гаралтыг хадгалах/дахин тараахыг зохицуулна. Үүнийг таамаг биш, **хуулийн шалгах жагсаалтын
зүйл** гэж үз.

### 3.4 Хэрэв чи хүн хөтлөгчөөр бичүүлэх бол

Тугийн сэдэвт үүнийг нухацтай бод: жүжигчилсэн тоглолттой жинхэнэ монгол хоолой (театрын маягийн
«Хоооот… унтлаа») бол neural хоолой гүйцэхгүй бодит ялгарал бөгөөд маркетингийн хөрөнгө болно (танил
монгол стример/жүжигчнийг хөтлөгчөөр авах).

Зардлын загвар — **бүх тариф нь [баталгаажаагүй], үнийн санал ав**:

```
clips              = 158
studio_hours       ≈ clips / 60 clips-per-hour × 1.5 (retakes) ≈ 4 hours
edit_hours         ≈ clips × 2 min ≈ 5 hours
total_cost         = (studio_hours × studio_rate) + (edit_hours × editor_rate) + talent_buyout
```

Дотоодын тарифыг дараах замаар шалга: монголын VO/дубляжийн Facebook бүлгүүд, MNB/Mongol TV-ийн радио
продакшны алба, УБ-ын дуу бичлэгийн студиуд, эсвэл Chimege (тэд бас хүний дуу бичлэг хийдэг). Тоглолтын
туршилтын дараа өөрчлөгдөх мөрүүдэд нэг дахин бичлэгийн сесс төсөвлө.

## 4. Соёлд суурилсан гурван арьс

Арьс бүр нь *зөвхөн нэр томьёо ба зургийг* сольдог — төлөвийн машин нь яг адилхан. Толийг ижил мөрийн
ID-аар түлхүүрлэсэн `theme.json` болгож гаргаж өг.

### 4.1 «ШӨНИЙН ЧОНО» — тал нутаг / өвөлжөө

Өвөлжөө. Чононууд шөнөөр хяраар буугаад мал — бас хүн авдаг.

| Механикийн дүр | Сэдэвчилсэн дүр | Яагаад тохирох вэ |
|---|---|---|
| Мафи | **Чоно** | Малчин айлд чоно бол бодитой, мэдрэгддэг шөнийн аюул. |
| Ахлагч | **Ноход** / **Цөвүүн чоно** | |
| Иргэн | **Малчин** | |
| Эмч | **Бариач** (уламжлалын бариа засалч) | Ерөнхий эмч биш, жинхэнэ монгол. |
| Мөрдөгч | **Мөрчин** / **Мөр хөөгч** | ⭐ Төгс тохирц: цасан дээрх мөрөөр чоно мөшгих нь шалгах механик өөрөө мөн. |
| Манаач | **Манаач** (шөнийн харуул) | |
| Саатуулагч | **Нохой** (хашааны нохой) | Нохой хуцаад дайрагч ухарна — шууд ойлгогдоно. |
| Хөтлөгч | **Айлын ахмад** | |

**Урлагийн чиглэл:** гүн индиго шөнө (**#131C34**) дээр Тэнгэрийн заадас; тооноороо улбар шар зуухны гэрэл
асгарсан гэрийн дүрс; эсгий, хивсний бүтэц; хөх-саарал («бөртэ») чоно; хөзрийн ар тал дээр **улзий**
хээний хүрээ; гэрийн дээврийн мурий дагасан булангийн радиус; хяруу/уурын тоосонцор. Дуу: морин хуурын
шуугиан, салхи, алсын улих.

**Бодит соёлоос гарсан сайхан механик:** монгол анчид шөнө `чоно` гэж чангаар хэлэхийн оронд *хүндэтгэлийн
үг* хэрэглэдэг. Хөтлөгч `хээрийн юм` гэж хэлж болно — үнэгүй уур амьсгал, дээрээс нь жинхэнэ соёлын
хичээл.

⚠ **Мэдрэг зүйлсийн анхааруулга:** (1) `Бөртэ чоно` бол *Монголын нууц товчоо*-н дээрх өвөг дээдэс —
төрөөс хүндэтгэсэн бичиг (2004 оноос алтадсан хувь нь Төрийн ордонд байрладаг). Муу санаатныг **сүргийн
махчин** хэвээр нь үлдээ, «монголчуудын өвөг дээдэс» болгож хэзээ ч бүү дүрсэл. Антагонистыг Бөртэ чоно
гэж бүү нэрлэ. (2) `хас` тэмдгийг **бүү хэрэглэ** — олон улсад нацист бэлгэдэл гэж уншигдана, дэлгүүрийн
жагсаалт чинь тэмдэглэгдэнэ. Оронд нь `улзий` ашигла.

### 4.2 «МАНГАСЫН ШӨНӨ» — аман зохиол

Туульсын ертөнц дэх айл; дүрээ хувиргадаг **мангас** (Жангар/Гэсэрийн туульсын сонгодог олон толгойт
мангас) тэдний дунд алхаж байна.

| Механикийн дүр | Сэдэвчилсэн дүр | Тэмдэглэл |
|---|---|---|
| Мафи | **Мангас** | Тодорхой *үлгэрийн* антагонист, лууны адил — амьд шашны асуудал байхгүй. |
| Иргэн | **Айлынхан** | |
| Эмч | **Шившлэгч** (хамгаалах шившлэг уншдаг хүн) | |
| Мөрдөгч | **Зурхайч** | Одоор нуугдмалыг олно — гоё. |
| Саатуулагч | **Илбэчин** | |
| Хөтлөгч | **Тууль**ч | |

**Урлагийн чиглэл:** Занабазарын үеийн буддын зураглал ба орчин үеийн монгол номын чимэглэлээс сэдэвлэсэн
туульсын шугаман зураг; бэх-алтны өнгөний багц; товхимлын ирмэг хэлбэрийн UI хүрээ; модон сийлбэрийн
бүтэц. Дуу: хөөмий, туулийн уншлагын хэмнэл, хүрээт бөмбөр.

⚠ **Мэдрэг зүйлсийн анхааруулга — гурвуулангийн хамгийн хатуу нь.** Монголын бөө мөргөл (бөө/удган) болон
буддын шашин бол үхмэл домог биш, **амьд шашин**. Дараах зүйлийг **бүү хий**: жинхэнэ **бөө/удган**-ыг
тоглоомын хэсэг болгох; **онгон** сахиус, бөөгийн хэнгэрэгийг эд зүйл болгож үзүүлэх; **Эрлэг хан**,
Тэнгэр, эсвэл нэр бүхий ямар нэг бурхныг муу санаатан болгох; хүмүүс өнөөдөр мөргөдөг жинхэнэ ариун
**овоо** дээр алалт тавих; лам/хуврагийн дүр төрх ашиглах. `мангас`, `шулам`, `илбэчин` — бүгд илэрхий
зохиомол үлгэрийн амьтад — дээр л үлдвэл бүх сэдэв аюулгүй байна. Нэг монгол соёлын шинжээчээр заавал
хянуул.

  ярьдаг хүмүүс бол чиний бай бүлгийн *эцэг эх, өвөө эмээ* нь, англи хэл сурч байгаа 12–18 насныхан биш.
  **[баталгаажаагүй статистик — монголын гадаад хэлний одоогийн судалгаа олдсонгүй; Үндэсний статистикийн
  хороо (nso.mn) эсвэл БШУЯ-ны сургалтын хөтөлбөрийн өгөгдлөөр шалга.]**

Хожим нэмэх аргумент, энэ дарааллаар:

1. **Англи** — iOS-ийн дэлгүүрийн жагсаалтад яахын аргагүй хэрэгтэй, байгалийн нөөц locale бөгөөд гадаадад
   «монголчуудын хийсэн тоглоом» гэсэн хэвлэлийн өнцгийг нээж өгнө. Онлайн горим гарах үед нэм.
2. **Орос** — орос хэлний «Мафия» орчин том бөгөөд дүрмийн үгсийн сан нь бараг ижил (`комиссар`, `дон`,
   `шериф`, `оправдание`), тиймээс *дүрэм* нь бараг тэг дизайны ажлаар хөрвөнө. Энэ бол **зөвхөн онлайн
   горимд** хамгийн өндөр өгөөжтэй хоёр дахь хэл.
3. Казах / Өвөр монголын уламжлалт бичиг — байвал сайхан, арилжааны биш.

**Инженерийн үр дагавар:** *локалчлагдах боломжтой байх* ажлыг (ICU түлхүүр, мөр залгахгүй, зураг дотор
текст шатаахгүй, бүх зүйлд `Intl`, `dir`/фонтын token) v1-д хийчихээд, зүгээр л хоёр дахь багцаа
гаргахгүй. Энэ нь ойролцоогоор хоёр өдөр зарцуулаад, дараа нь нэг сарыг хэмнэнэ.

# Бүлэг 01 — Тоглоомын дүрэм ба үе шатын бүтэц

> **Гол дүгнэлт**
>
> - Чиний ангийн тоглодог Мафи бол Америкийн **Werewolf** салаа биш, **Оросын «спорт мафи»** салаа юм.
>   Дугаарласан суудал, танилцах шөнө, ээлжит 60 секундын үг, «лучший ход» (шилдэг сонголт) — эдгээр нь
>   энэ уламжлалын онцлог. Тиймээс офлайн горимын үндсэн дүрэм Орос конвенцийг, онлайн горим нь Town of
>   Salem конвенцийг дагах ёстой.
> - Тоглоом **Шөнө**-өөс эхэлнэ, Шөнө 0 дээр хэн ч үхэхгүй (зөвхөн танилцана). Энэ нь «Өдөр 1-д ярих юм
>   алга» гэдэг гол асуудлыг шийднэ.
> - Ялалтыг **элиминаци бүрийн дараа шууд** шалгана, үе шатын төгсгөлд биш. Мафи `M ≥ T` болмогц хожно
>   (parity буюу тэнцвэрийн дүрэм). «Бүгдийг ална» гэсэн хуучин дүрмийг битгий хэрэглэ.
> - Тоглогчийн **нийт тоо сондгой** байвал хотод илүү тустай (arXiv:2408.17177). Мафийн тоо ойролцоогоор
>   `M = floor(N / 3.5)`.
> - Мөрдөгч байхад мафи өрсөлдөхийн тулд хүн амын **шугаман хувь** хэрэгтэй болдог (Braverman нар, 2008).
>   Тиймээс Ахлагч (Дон) дүр буюу илрүүлэлтээс дархлаатай мафи заавал хэрэгтэй.
> - Хөтлөгчийн бүх дуудлагыг апп өөрөө монголоор ярина; шилжилт бүр аудиогоор жолоодогдож, дараа нь таймер
>   ажиллана.

## 2. Хөтлөгчийн скрипт, үе шат тус бүрээр (яг дуудлагууд)

### 2.1 Plotkin 1997 (англи канон, үгчлэн)

Доорх блок бол 1997 оны англи хувилбарын хөтлөгчийн скрипт. Кодын нэг хэсэг шиг яг энэ дарааллаар
уншигдана; зүүн талд дуудлага, баруун талд хөтлөгч юу хийхийг тайлбарласан.

```
"Close your eyes."
"Werewolves, open your eyes."            → wolves identify each other silently
"Werewolves, pick someone to kill."      → agreement by pointing/nodding; moderator confirms
"Werewolves, close your eyes."
"Seer, open your eyes."
"Seer, pick someone to ask about."       → moderator: thumbs UP = werewolf, thumbs DOWN = villager
"Seer, close your eyes."
"Everybody open your eyes; it's daytime." → moderator names the victim
```

**Өдөр:** чөлөөт хэлэлцүүлэг, дараа нь санал. *«As soon as a majority of players vote for a particular
player to die, the moderator says "Ok, you're dead."»* Хөзрийг ил болгоно. *«Dead players may not speak
at all.»*

**Ялалт:** *«The humans win if they kill both werewolves. The werewolves win if they kill enough
villagers so that the numbers are even.»* Санал болгох тоглогчийн тоо: *«at least seven players; nine
or eleven is better.»* — доод тал нь **7**, **9** эсвэл **11** бол илүү сайн.

### 2.3 Сэрэх дараалал — дараалал үнэхээр чухал, үүнийг хэрэглэ

Хоёр өөр дарааллыг ялгаж ойлго: **сэрэх дараалал** (хэнийг дуудаж байна) ба **тооцох дараалал**
(нөлөөг хэрхэн бодож гаргах). Mafiascum-ийн стандарт нь **Natural Action Resolution (NAR)**:
*бусад үйлдлийг өөрчилдөг үйлдлийг, өөрчлөгдөж буй үйлдлээс нь өмнө хэрэгжүүл*, мөн бүх алалтыг
шөнийн төгсгөлд **нэгэн зэрэг** болсон гэж үз.

| # | Сэрэх дараалал (дуудлага) | Яагаад яг энд байна вэ |
|---|---|---|
| 1 | Мафи бие биенээ таних (зөвхөн Шөнө 0) | Ямар ч сонголт хийхээс өмнө болох ёстой |
| 2 | Мафийн алах бай тодорхойлох | Дараагийн дүрүүдэд хөтлөгчид бай хэрэгтэй |
| 3 | Ахлагч (Дон) / мафийн даргын шалгалт (Орос салаа) | Бие даасан |
| 4 | Саатуулагч / «любовница» (хэрэглэсэн бол) | Бусад үйлдлийг өөрчилдөг → эхэлж тооцогдоно |
| 5 | Эмч / эдгээгч | Хөтлөгч алалтыг мэдсэний дараа, ил болгохоос өмнө байх ёстой |
| 6 | Мөрдөгч / шериф / комиссар | **Хамгийн сүүлд** дууд — ингэснээр хөтлөгч бүх томилолтыг аль хэдийн мэдэж байна |
| 7 | «Бүгд сэр» + үхлийн зарлал | — |

**Шөнийг тооцох псевдо-код (шууд хэрэгжүүлэхэд бэлэн).** Доорх алгоритм нь нэг шөнийн бүх үйлдлийг
зөв дарааллаар боловсруулна: эхлээд саатуулалт, дараа нь хамгаалалт, дараа нь алалт, эцэст нь шалгалт.
Чухал зүйл: шалгалтын хариуг **анхны харьяалал**-аар өгнө, үхсэн эсэхээс хамаарахгүй.

```
resolveNight(actions):
  1. roleblocks  = actions.filter(BLOCK)        // apply first
  2. mark blocked targets; drop their actions
  3. protections = actions.filter(PROTECT)      // doctor, bodyguard
  4. kills       = actions.filter(KILL)         // mafia kill, serial killer
  5. for each kill k:
        if k.target in protections and protection not blocked: k.cancelled = true
  6. investigations = actions.filter(INVESTIGATE)
        // resolve against ORIGINAL alignment, not post-death state
  7. deaths = kills where !cancelled           // all kills simultaneous
  8. apply deaths -> emit NightReport
  9. checkWinCondition()                       // see §6
```

> **Юу гэсэн үг вэ?** *Roleblock (Саатуулах)* — нэг тоглогчийн шөнийн чадварыг ажиллуулахгүй болгох.
> Саатуулагч Эмчийг саатуулбал Эмчийн аврах үйлдэл ажиллахгүй, тиймээс хохирогч үхнэ. Тиймээс
> саатуулалтыг **хамгийн түрүүнд** тооцох ёстой.

## 6. Ялах нөхцөл ба түүнийг яг хэзээ шалгах вэ

| Дүрмийн багц | Хотынхон хожно | Мафи хожно | Шалгах цэг |
|---|---|---|---|
| Plotkin 1997 | бүх чоно үхсэн | чоно ≥ чоно-бус («numbers are even») | үхэл бүрийн дараа |
| brenbarn хөтлөгчийн гарын авлага | чоно амьд үлдээгүй | *«the number of wolves is equal to or greater than the number of non-wolves»* | тасралтгүй |
| Оросын ФСМ | 3 хар бүгд хасагдсан | хар ≥ улаан, *«санал өгөх агшин эсвэл шөнийн алалтын агшинд»* шалгана | **элиминаци бүр дээр шууд**, үе шатын төгсгөлд биш |

**Үүнийг ингэж хэрэгжүүл.** Доорх функцийг **элиминаци бүрийн дараа** дуудна — үе шатын төгсгөлд биш.
Гуравдагч талын (Ганцаарчин, Jester) ялалтыг хоёр фракцын шалгалтаас **өмнө** тооцно.

```
checkWin(state):                       // call after EVERY elimination, not at phase end
  mafia = alive.count(faction == MAFIA)
  town  = alive.count(faction == TOWN)
  if mafia == 0:            return TOWN_WIN
  if mafia >= town:         return MAFIA_WIN      // PARITY rule (default)
  // third parties evaluated BEFORE the two-faction check:
  if serialKiller.alive and alive.size <= 2: return SK_WIN
  if jester.lynched:        return JESTER_WIN     // resolves instantly, game may continue
  return CONTINUE
```

Хоёр өөр гэр бүлийн дүрэм байдаг бөгөөд тэдгээр нь **тэнцүү биш**:

- **Parity дүрэм** (`mafia >= town`) — стандарт, тоглоомыг эрт дуусгаж, утгагүй сүүлчийн өдрөөс
  зайлсхийнэ.
- **Elimination дүрэм** (`town == 0`) — мафи шууд бүгдийг алах ёстой. Удаан, хурдны хувьд илт муу.
  Зарим хуучин Оросын клубын текст үүнийг хэрэглэдэг («бүх шударга иргэн хасагдсан эсвэл шоронд орсон»).
  **Parity-г хэрэглэ.**

**UI-д харуулах эцсийн шатны нэр томьёо** (Mafiascum — **[эх сурвалж БАТАЛГААЖААГҮЙ 2026-09-15, wiki нь
Cloudflare-т хаагдсан; арифметикийг гараар шалгаж зөв болохыг тогтоосон]**; анхаар: MafiaWiki эдгээрийг
одоо *Eliminate-or-Lose* ба *Miseliminate-and-Lose* гэж нэрлэдэг):

| Нэр | Хуучин утга | Нөхцөл | Хотынхны хувьд юу гэсэн үг вэ |
|---|---|---|---|
| **LYLO** | *Lynch or Lose* | хотынхон мафигаас яг **нэгээр** илүү (ж нь: 3 хот / 2 мафи) | Өнөөдөр заавал мафи оносон байх ёстой. Алдвал дуусна |

| arXiv 2408.17177 (2024), *Optimal Strategy in Werewolf Game* | Чонын хожих магадлалын рекурс `w(n,m)`: `w=0 if m=0`; `w=1 if m ≥ n−m`; `w = 1−(1/2)^(m+1)` if `n−1 = 2m, n ≥ 5`; бусад тохиолдолд `w(n,m) = ((n−1−m)/(n−1))·w(n−2,m) + (m/(n−1))·w(n−2,m−1)`. Томьёог 2026-09-15-нд өгүүлэлтэй үгчлэн тулгаж шалгасан. Ганц зохиогч: **Shitong Wang** |

> **Баталгаажуулалт (2026-09-15):** **[ЗАСВАРЛАСАН]** Өмнөх тайланд сондгой/тэгшийн чиглэл **урвуу**
> байсан. Өгүүлэлд бичсэнээр `w(n,m) > w(n−1,m)` бол **n тэгш** үед, `w(n,m) < w(n−1,m)` бол **n сондгой**
> үед (хоёул `n ≥ 2m+1` нөхцөлд). Өөрөөр хэлбэл **тэгш** нийт тоонд нэг иргэн нэмбэл (сондгой болгоно)
> чонын хожих магадлал *буурна*; **сондгой** тоонд нэг иргэн нэмбэл (тэгш болгоно) *өснө*.
> *«when the number of all players n is odd, adding one villager is not enough to add an extra round …
> but makes the chance of werewolves being voted out smaller in each round.»*

> Эх сурвалж: https://arxiv.org/html/2408.17177v1

## 8. Орос / Төв Азийн «спорт мафи» — энэ төслийн өвлөж авсан салаа

Энэ хэсэг хамгийн чухал, учир нь Монголын ангийн Мафи бол Зөвлөлтийн хувилбараас гаралтай.

**Бүрэлдэхүүн.** 10 тоглогч, 1–10 дугаартай суудал, харагдахгүй нүүрний хаалт (нүд таглах маск),
төвийг сахисан **Шүүгч** (Судья). 7 «улаан» (6 иргэн + Мөрдөгч), 3 «хар» (2 алуурчин + Ахлагч).

**Шөнө 0 — «договорка» (тохиролцоо).** Шүүгч: *«наступает ночь»*. Хар баг маскаа авч,
**яг 1 минутын турш** бие биетэйгээ танилцана; Ахлагч дараагийн шөнүүдийн буудах дарааллыг тогтооно.
Дараа нь Ахлагч өөрийгөө шүүгчид дохино (**≤10 секунд**), дараа нь Мөрдөгч өөрийгөө дохино
(**≤10 секунд**). Дараа нь **40 секундын «чөлөөт суух»** цонх — гар ширээн дээр, толгой ~45° хазайсан
байна. **Шөнө 0-д алалт байхгүй.**

**Өдөр.** Амьд тоглогч бүр **яг 60 секунд** авна; Өдөр 1-д №1 тоглогчоос эхэлж, өдөр бүр дараагийн
дугаар руу шилжинэ. Үг *«ПАС»* эсвэл *«СПАСИБО»* гэж дуусна. Нэр дэвшүүлэлт зөвхөн өөрийн үгийн үед:
*«Я выставляю игрока № …»*, **өдөрт тоглогч тутамд дээд тал нь 1 нэр дэвшүүлэлт**.

> **Баталгаажуулалт (2026-09-15):** **[засварласан]** Санал өгөхөд ≥2 нэр дэвшигч байх шаардлага нь
> бүх нийтийнх *биш*. dom-mafia.ru §4.4.10:
> *«Если в первый игровой „день“ выставлена только одна кандидатура, то голосование не проводится.
> В течение следующих „дней“ голосуется любое количество выставленных на голосование игроков.»* —
> өөрөөр хэлбэл ганц нэр дэвшигч нь **зөвхөн Өдөр 1 дээр** саналыг зогсооно; Өдөр 2-оос эхлэн нэр
> дэвшигчийн ямар ч тоо (нэг ч байсан) санал өгөгдөнө.
> Эх сурвалж: https://dom-mafia.ru/sport_mafia_game_rules, 2026-09-15-нд татсан.

**Санал өгөх.** Нударгаа босоо өргөнө, тус бүр ~**1.5 секунд**; шүүгч *«Стоп»* гэх хүртэл гар дээрээ
байна. Хамгийн олон санал авсан нь ширээнээс гарна. **Дүрийг ил болгохгүй.** Хасагдсан тоглогч
**1 минутын сүүлчийн үг** авна.

**Тэнцэх («перестрелка»).** Тэнцсэн тоглогчид тус бүр **+30 секунд** авч, дараа нь дахин санал өгнө.
Дахин тэнцвэл давтана. Мөн тэр нэр дэвшигчид дээр гурав дахь удаагаа тэнцвэл шүүгч ширээнээс асууна:
*«Кто за то, чтоб все голосуемые игроки покинули игровой стол?»*; олонх дэмжвэл тэнцсэн **бүгд** гарна,
эс бөгөөс хэн ч гарахгүй.

**Шөнө (энгийн).** *«Мафия выходит на охоту»*; шүүгч 1…10 хүртэл тоолж, хар тоглогчид нүдээ анисан
хэвээр сонгосон дугаар дээрээ гар өргөнө. **Хэрэв хар нар бүгд ижил дугаар руу заагаагүй бол буудлага
оногдохгүй** бөгөөд хэн ч үхэхгүй. Дараа нь Ахлагч сэрж, нэг дугаар заана; шүүгч тийм/үгүй гэж толгой
дохино («энэ Мөрдөгч мөн үү?»). Дараа нь Мөрдөгч сэрж заана; шүүгч **эрхий дээш = улаан, эрхий доош =
хар** гэж хариулна. Шөнөдөө тус бүр нэг шалгалт.

**«Лучший ход» (шилдэг сонголт).** **Шөнө хамгийн түрүүнд алагдсан тоглогч** (ПУ — первый убитый)
маскаа тайлалгүйгээр **20 секунд** авч, хар гэж бодож буй **гурван** тоглогчийн дугаарыг нэрлэнэ.
Шүүгч тэмдэглээд чангаар уншина. Онооны урамшуулал: **3 зөв бол +0.5, 2 зөв бол +0.25**. Хэрэв Өдөр 1-ийн
санал өгөлтөөр **2 буюу түүнээс олон тоглогч ширээнээс гарсан бол хүчингүй болно**. Өөрийнхөө шилдэг
сонголтыг дүрээ батлах баримт болгон ашиглах нь өөрөө фол.

**Фол (зөрчил).**

| Төрөл | Жишээ | Шийтгэл |
|---|---|---|
| Энгийн фол (фол), §6.6 | өөрийн минутаас гадуур ярих (үүнд үг хавчуулах, шивнэх, уншигдахуйц уруул хөдөлгөх), хэт их дохио зангаа, **өдрийн** үед хүрэлцэх, ширээ цохих / тоглогч, шүүгчид ёс бус хандах, шүүгчтэй маргах, санал тоологдохоос өмнө гараа буулгах, санал өгөх үе шатанд дохих эсвэл ухуулах, тогтоосон саналын **дараалал** зөрчих | 3 дахь фол = дараагийн үгээ алдана (нэр дэвшүүлж болно); **4 дэх = сүүлчийн үггүйгээр тоглоомоос хасагдана** |
| Хасах фол (дисквалификаци), §6.7 | ширээнээс гарах, **шөнийн** үед хүрэлцэх, шөнө Ахлагч/Мөрдөгч рүү дохих, доромжлох, шөнө нүдээ нээж харах, шөнө ярих/хашгирах, ширээн дээр уйлах, тоглоомоос гадуурх ятгалга (*«честное слово, я красный»*, *«видит Бог»*), **буруу хэлбэрээр санал өгөх** — *«голосование ладонью, пальцем, локтем и т.п., голосование против нескольких кандидатур, голосование двумя руками»* — мэдээлэл олж авахын тулд санаатай хууран мэхлэх, шилдэг сонголтод тодорхой нэр шаардах, хажуугийн хүнд өдрийн онцгой мэдээлэл шивнэх, гадаад хэлээр утга нуух, бүдүүлэг үг | шууд хасах; зөрчигчийн баг тоглоомоо алдаж болно; рейтинг **−0.5** |

> **Баталгаажуулалт (2026-09-15):** **[засварласан]** Буруу *хэлбэрээр* санал өгөх (алгаараа / хуруугаараа
> / тохойгоороо / хоёр гараараа, эсвэл хэд хэдэн нэр дэвшигчийн эсрэг санал өгөх) явдлыг өмнө нь
> **энгийн** фол гэж бичсэн байсан. dom-mafia.ru §6.7-оор энэ бол **хасах** фол; зөвхөн саналын
> *дарааллыг* зөрчих нь (§6.6) энгийн фол болно.
> Эх сурвалж: https://dom-mafia.ru/sport_mafia_game_rules, 2026-09-15-нд татсан.

**Рейтинг.** Хожвол тоглогч тутамд **1 оноо**; хожигдвол/тэнцвэл **0**; дисквалификаци **−0.5**; шүүгчийн
үзэмжийн урамшуулал **+0.1…+0.7** (хожигчид) / **+0.1…+0.4** (хожигдогчид); тоглоомыг алдуулсан том
алдаа **−0.4**. Тэнцсэн үеийн эрэмбэ: урамшууллын оноо → хожил → Ахлагч/Мөрдөгчөөр хожсон тоо →
эхний шөнийн алалт → сугалаа.

## 11. Хэрэгжүүлэх төлөвийн машин

Доорх диаграм бол тоглоомын нэг бүтэн мөчлөг. `[ ... ]*` хаалт нь тоглоом дуустал давтагдах хэсэг;
`?` тэмдэгтэй алхмууд нь тохиргооноос хамаарч алгасагдаж болно.

```
LOBBY → ROLE_DEAL (pass-the-phone reveal) → NIGHT_0(acquaintance, no kill)
  → [ DAY_ANNOUNCE → BEST_MOVE? → LAST_WORD? → DISCUSSION/SPEECH_ROUND
      → NOMINATION → (VOTE → TIE_SPEECH → REVOTE → ALL_OUT_VOTE)? → ELIMINATION → LAST_WORD?
      → checkWin
      → NIGHT(mafia kill → don check → doctor → detective) → resolveNight → checkWin ]*
  → GAME_OVER(reveal all roles, stats)
```

Шилжилт бүр офлайн горимд **хөтлөгчийн аудиогоор жолоодогдох** ёстой (утас монгол дуудлагыг хэлээд,
дараа нь таймер ажиллуулна), онлайн горимд **серверийн эрхтэй** (server-authoritative) байх ёстой.

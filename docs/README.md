## Аргачлал

Чиглэл бүрийг нэг agent гүнзгий судалж, дараа нь **өөр agent түүнийг няцаахыг оролдсон** —
тоо бүрийг анхдагч эх сурвалжаас нь дахин шалгаж, буруу зүйлийг файл дотор нь шууд зассан.
Ингэж **139 алдаа** илэрсэн — үүний нэг нь бүхэл бүлгийн гол дүгнэлтийг няцаасан (Бүлэг 20).

Бүлэг дотор «> **Баталгаажуулалт (2026-09-15)**» гэсэн иш татсан хэсэг тааралдвал тэр нь
*анхны судалгаа буруу байсан газар* гэсэн үг — залруулга нь эх сурвалжтайгаа хамт хадгалагдсан.

«[баталгаажаагүй]» гэж тэмдэглэсэн зүйлийг шийдвэрийн үндэс болгож болохгүй. Тухайн газар
нь хэрхэн шалгахыг бичсэн байгаа.

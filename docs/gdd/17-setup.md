# GDD-17 — Ажлын орчин бэлтгэх

> **Шийдвэрийн хураангуй**
> - **Эхлээд зөвхөн Flutter + Chrome + VS Code суулга.** Android Studio-г ХОЙШЛУУЛ. Энэ гурав ~4 ГБ, Android Studio нэмэх нь ~12 ГБ болгоно. GDD-19-ийн шийдвэрээр эхний гаргах хувилбар нь вэб (PWA) тул Android SDK эхний 2 сард огт хэрэггүй.
> - **Эмулятор битгий ашигла, жинхэнэ утсаа USB-ээр холбо.** Эмулятор 2–4 ГБ RAM иднэ; чиний зорилтот төхөөрөмж яахнаа хямд Android (GDD-13-ын D1 = Redmi 9A / 2 ГБ) тул жинхэнэ утсан дээр тестлэх нь хурдан бөгөөд үнэн.
> - **GitHub дээр гурван согог байсныг зассан** (GDD-19 §1): `main` салбар байхгүй байсан, Pages хэзээ ч асаагүй, deploy workflow нь `docs/`-ийн бүлгүүдийг татагддаг файл болгож үзүүлэх байсан.
> - **Одоо байхгүй ганц том зүйл: `app/` Flutter төсөл.** `packages/engine` ажиллаж байгаа ч дэлгэцтэй апп хараахан байхгүй.
> - **Хамгийн бага техник: 8 ГБ RAM, 20 ГБ сул зай, SSD.** 4 ГБ RAM дээр Flutter ажиллана ч VS Code + Chrome + build зэрэг явахад гацна.

## 2. Заавал суулгах гурван зүйл

Дарааллаараа хий. Нийт ~4 ГБ, ~40 минут (интернэтээс хамаарна).

### 2.1 Git

Хэрэв `git --version` ажиллаж байвал алгас.

- Windows: <https://git-scm.com/download/win> (~60 МБ)
- macOS: `xcode-select --install`

Дараа нь нэг удаа тохируулна:

```bash
git config --global user.name "Чиний нэр"
git config --global user.email "khuchee31@gmail.com"
```

### 2.2 Flutter SDK

Flutter дотор **Dart аль хэдийн багтсан** — Dart-ыг тусад нь суулгах шаардлагагүй.

- <https://docs.flutter.dev/get-started/install> → үйлдлийн систэмээ сонго
- Татах хэмжээ ~1.2 ГБ, задлахад ~3 ГБ

**Windows дээр `C:\src\flutter` руу задал.** `C:\Program Files` руу задлах ХЭРЭГГҮЙ — тэнд бичих эрх шаардагддаг тул Flutter эвдэрдэг. Дараа нь `C:\src\flutter\bin`-ийг `Path` орчны хувьсагчид нэм.

Шалгах:

```bash
flutter --version
flutter doctor
```

`flutter doctor` улаан загалмайнуудыг харуулна — **одоохондоо санаа зовох хэрэггүй**. Зөвхөн энэ хоёр мөр ногоон байхад л хангалттай:

```
[✓] Flutter (Channel stable, 3.x.x)
[✓] Chrome - develop for the web
```

### 2.3 VS Code + өргөтгөл

- <https://code.visualstudio.com> (~100 МБ)
- Дотор нь Extensions → **«Flutter»** (Dart өргөтгөлийг өөрөө дагуулж татна)

Android Studio-г суулгах ШААРДЛАГАГҮЙ. Түүнийг зөвхөн Android-ын APK гаргах үед (GDD-16 §1-ийн W16 орчим) суулгана.

## 3. Эхний ажиллуулалт — 10 минут

Repo-гоо clone хийгээд хөдөлгүүрийн тестийг ажиллуул. Энэ нь бүх зүйл зөв суусан эсэхийн **бодит шалгалт**:

```bash
git clone https://github.com/khuchee31-gif/Ytasnii-app.git
cd Ytasnii-app/packages/engine
dart pub get
dart test
```

Хүлээгдэж буй үр дүн:

```
00:04 +211: All tests passed!
```

Хэрэв энэ ажиллавал **чиний орчин бүрэн бэлэн**. Хэрэв `dart` олдохгүй бол Flutter-ийн `bin` нь `Path`-д ороогүй байна.

Дараа нь хаалганы fuzz (~3 минут, заавал биш):

```bash
dart run tool/fuzz.dart
```

## 4. Утсаа холбох (эмуляторын оронд)

1. Утсан дээрээ **Тохиргоо → Утасны тухай → Build number** дээр **7 удаа** дар. «Та хөгжүүлэгч боллоо» гэж гарна.
2. **Тохиргоо → Систем → Хөгжүүлэгчийн сонголт → USB debugging** асаа.
3. USB-ээр компьютерт залга. Утсан дээр «Энэ компьютерт зөвшөөрөх үү?» гарвал **Зөвшөөрөх**.
4. Шалгах:

```bash
flutter devices
```

Утас жагсаалтад гарах ёстой. Гарахгүй бол: кабель нь зөвхөн цэнэглэдэг кабель байж магадгүй (өгөгдөл дамжуулдаг кабель хэрэгтэй), эсвэл Windows дээр үйлдвэрлэгчийн USB драйвер дутуу.

**Хятад брэндүүд** (Xiaomi, Huawei, Oppo, Vivo) дээр нэмэлт алхам: Хөгжүүлэгчийн сонголтоос **«Install via USB»** эсвэл **«USB debugging (Security settings)»**-г бас асаах шаардлагатай. Xiaomi дээр үүнд Mi данс руу нэвтэрсэн байх шаардлагатай байдаг.

## 5. GitHub дээр юу зассан бэ

GDD-19 §1 гурван согог олсныг энэ бүлэгтэй хамт зассан:

| Согог | Юу байсан | Одоо |
|---|---|---|
| `main` салбар байхгүй | deploy workflow `main` руу push хийхэд ажиллахаар бичигдсэн атлаа тэр салбар огт байгаагүй → **хэзээ ч ажиллаагүй** | `main` үүсгэв |
| Pages асаагүй | GitHub API `has_pages: false` буцаадаг байсан | workflow `enablement: true`-тэй, эхний push дээр асна |
| `path: "."` | Бүх repo-г түүхийгээр нь байршуулна → `docs/`-ийн 37 бүлэг **татагддаг .md файл** болж харагдана | зөвхөн `site/` хавтас байршина |

**Чи GitHub дээр өөрөө хийх ёстой ганц зүйл:** repo-гийн **Settings → Pages → Source** хэсгийг **«GitHub Actions»** болгож сонго (хэрэв автоматаар болоогүй бол).

## Нээлттэй асуулт

1. **Чиний компьютер ямар вэ?** RAM, сул зай, SSD эсэх. 4 ГБ RAM бол дээрх зөвлөмж өөрчлөгдөнө (вэб-only, эмуляторгүй).
2. **Ямар утастай вэ?** Android эсэх, хэдэн ГБ RAM-тай. Энэ нь GDD-13-ын D1 төхөөрөмжийг тодорхойлно.
3. **Интернэт хэр хурдан вэ?** 4 ГБ татахад хэр удах вэ — сургууль дээрээ татах уу, гэртээ юу.

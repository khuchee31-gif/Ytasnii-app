# GDD-07 — Хөтлөгчийн бүрэн скрипт ба аудио каталог

> **Шийдвэрийн хураангуй**
> - **v1-д яг 141 клип.** Үүнээс **80 нь M4a** (жинхэнэ хүний хоолой, буулт хийхгүй), **61 нь M4b** (хоцровол Azure-аар рендерлээд эхний засварт солино). Клип бүрийн ID, монгол текст, урт, үе шат, шаардлагатай эсэх нь `assets/vo/clips.csv` дотор — **тэр файл бол цорын ганц үнэн**, хүний студийн скрипт ба Azure-ийн рендер скрипт хоёулаа түүнээс үүсдэг.
> - **Суудлын дугаар нь 20 бие даасан клип** (`SEAT_01…SEAT_20`), бөгөөд **үүрийн хохирогчийн мөр нь дахин 20 өөрийн клип** (`DAWN_VICTIM_01…20`). Өөр хаана ч дугаарыг залгаж хэлнэ, зөвхөн үүрийн мөрөнд л залгаагүй бүтэн өгүүлбэр бичигдэнэ — тэр нь тоглоомын хамгийн драмтай хоёр секунд, залгааны үе тэнд харагдаж болохгүй.
> - **Шөнийн эргэлтийн дүрийн асуултууд аудио БИШ.** «Хэнийг аврах вэ?», «Хэнийг шалгах вэ?», «Мөр олдлоо» — бүгд **зөвхөн дэлгэцийн текст**. Хоолой нь эргэлтийн үед зөвхөн жигд дуудлага хэлнэ: «Дараах —» + суудлын дугаар + «Утсаа ав.» Ингэснээр жигд хуурмаг эвдрэхгүй.
> - **Апп аврагдсаныг хэзээ ч хэлэхгүй.** `DAWN_NO_KILL` = «Өнөө шөнө хохирогч гарсангүй.» гэсэн **ганц** мөр. Эмч ажилласан эсэх, Мафи санал зөрсөн эсэх нь ялгагдахгүй — 4-р татгалзлын («хөтлөгч мэдээлэл зарахгүй») шууд үр дагавар.
> - **Чимээгүй нь файлын дотор биш, төлөвлөгчийн дотор.** Клип бүр толгой/сүүлдээ ≤30 мс чимээгүйтэй (**−60 dBFS** босгоор тайрагдсан), бүх завсар `NarratorQueue`-ийн `Duration`-оор өгөгдөнө, бөгөөд §3-ын хүснэгт нь **±80 мс** хүлцэлтэй интеграцийн тест болно.
> - **Бичлэгийн нийт цаг ≈ 10 хүний цаг:** студид **5.0 ц** (4 сесс), эвлүүлэг + QA + төхөөрөмжийн тест **4.6 ц**. Бэлэн зардал **₮0** — хоолойг ангийн жүжгийн дугуйлан эсвэл монгол хэлний багшаас авна, дэлгүүрийн хуудсанд нэрээр нь бичнэ.
> - **Azure бол нөөц, `flutter_tts` бол хориотой.** Синтезчилсэн аудиог апп дотор суулгаж тараах лицензийн асуулт **2027-01-10 хүртэл нээлттэй**; хариу ирэхгүй бол M4b нь хүний хоолойгоор хязгаарлагдаж, дутуу клипүүд **дэлгэцийн текст** болно. Runtime TTS ямар ч тохиолдолд байхгүй.

*Огноо: 2026-09-15. Заавал дагах эх сурвалж: `docs/gdd/00-vision.md` §5.1, §5.8, §9; `docs/13-language-culture.md` §1.1–1.4, §3.*

## 0. Нэг тэмдэглэсэн зөрчил

Үзэл баримтлалын §7 нь шөнийн эргэлтийн асуултуудыг («Хэнийг аврах вэ?», «Хэн сэжигтэй вэ?») хөтлөгчийн мөр шиг хашилтанд бичсэн, харин §5.1 нь аудио зөвхөн механик толийг хэлнэ гэж заасан. **Энэ хоёр нэг дор оршиж чадахгүй:** хэрэв хоолой «Хэнийг аврах вэ?» гэж чангаар хэлбэл тэр секундэд утас барьж байгаа хүн Эмч гэдгийг арван нэгэн хүүхэд сонсох бөгөөд жигд эргэлтийн бүх үнэ цэн (10 §2.2-ын жигд хуурмаг) тэр дороо үхнэ. **Тиймээс би §7-ийн тэр гурван хашилтыг дэлгэцийн текст гэж уншиж байна.** Дүрийн сэрэх/унтах клипүүд нь §5.8-ын шаардсанаар M4a-д **бичигдэнэ** — гэвч тэд зөвхөн хоёр газар тоглогдоно: (а) «Хуучин шөнө» тохиргоо (ФСМ-ийн хэлбэрийг хүссэн ширээнд), (б) Тохиргооны «Хөтлөгч юу хэлэх вэ?» гэсэн 40 секундын сонсгол. Жигд эргэлтийн дотор **хэзээ ч** тоглогдохгүй.

## 1. ID схем, файлын зохион байгуулалт, үнэний эх сурвалж

```
assets/vo/clips.csv          ← ЦОРЫН ГАНЦ ҮНЭН
assets/vo/bataa/SEAT_07.ogg  ← assets/vo/{voice}/{ID}.ogg
assets/vo/bataa/theme_wolf/…  ← сэдэвчилсэн нэмэлт (v2)
assets/sfx/…                  ← хоолой биш чимээнүүд, өөр төсөв
```

`clips.csv`-ийн баганууд, яг ийм дарааллаар:

| Багана | Төрөл | Тайлбар |
|---|---|---|
| `id` | `SCREAMING_SNAKE` | Латинаар, хэзээ ч орчуулагдахгүй |
| `mn` | текст | Бичигдэх монгол өгүүлбэр, точкотой нь |
| `phase` | enum | `setup · deal · night · circuit · dawn · day · vote · elim · reveal · end · hostmode` |
| `tier` | enum | `m4a` · `m4b` · `v2` · `v3` |
| `target_ms` | int | Урт зорилт; **±20%** давбал дахин бичнэ |
| `plays_per_game` | int | Амтлагч хувилбар хэрэгтэй эсэхийг шийддэг тоо |
| `variant_of` | ID / хоосон | Амтлагч хувилбар бол эх ID |

**Дүрэм 1.** Dart кодод бичигдсэн ID бүр `clips.csv`-д байх ёстой, `clips.csv`-ийн `tier ∈ {m4a, m4b}` мөр бүр `assets/vo/bataa/`-д файлтай байх ёстой. Хоёрыг CI шалгана; зөрвөл build унана.

**Дүрэм 2.** Өгүүлбэр залгах нь **зөвхөн** гурван хэлбэрээр зөвшөөрөгдөнө: `[PREFIX] + SEAT_nn`, `[PREFIX] + SEAT_nn + [SUFFIX]`, `SEAT_nn + [ROLE]`. Өөр ямар ч динамик мөр байхгүй — **дагавар үүсгэгч хөдөлгүүр огт бичихгүй** (13 §0).

**Дүрэм 3.** Тоглогчийн **нэр** хоолойд хэзээ ч гарахгүй. Зөвхөн суудлын дугаар. Энэ нь v1-д хэмнэлт, v3-д хавх (§9-ийн нээлттэй асуулт 8).

**Дэс тооны бичиглэл.** Бичигдэх текст нь стандарт хэлбэр — `нэгдүгээр`, `долоодугаар`, `арван зургаадугаар`, `хорьдугаар`. Үзэл баримтлалд «долоо дугаар» гэж зайтай бичигдсэн нь зөвхөн дэлгэцийн хуулбар дээрх бичиглэлийн хэлбэр; **дуудлага нь адилхан** тул аудионд ямар ч зөрчил үүсгэхгүй.

**Гурван шийдвэр энд байна.**

1. **`DAWN_VICTIM_nn` нь залгаа биш, 20 бүтэн өгүүлбэр.** Каталогийн өөр хаана ч дугаарыг залгаж хэлдэг; зөвхөн энд л биш. Шалтгаан нь драм: `DAWN_A`-ийн дараах 2.5 секундын дараа ирэх мөр бол тоглолтын хамгийн чанга агшин бөгөөд «…долоодугаар | тоглогч хохирлоо» гэсэн дунд нь залгаастай сонсогдох эрсдэлийг 20 клип, ~8 минутын студийн цагаар үнэлж авахгүй. Дуудлагын өнгө нь **бууж дуусах** ёстой (§5).
2. **Аврагдсаныг хэзээ ч зарлахгүй.** Эмч зөв хүнийг аварсан, Мафи санал зөрсөн, бай нь аль хэдийн хасагдсан — гурвуулаа **яг ижил** `DAWN_NO_KILL` гаргана. `DAWN_SAVED` гэсэн ID байхгүй бөгөөд хэзээ ч байхгүй.
3. **Шивнээний ба шилдэг нүүдлийн дугаарууд аудиогоор хэлэгдэхгүй** — хоолой зөвхөн «Хот шивнэж байна.» гэж хэлээд дэлгэцэн дээр хоёр дугаар гарна, ширээнээс хэн нэг нь чангаар уншина. Ижил дүрэм шилдэг нүүдэлд (үзэл баримтлал §7: «Хөтлөгч уншина»). Энэ нь **20 кардинал клип хэмнэж**, ширээг ярихад хүргэнэ. Тэр кардинал багц (`NUM_01…20`) v2-т орно, §8.

Санамсаргүй сонголт нь ижил хувилбарыг гурав дараалан гаргаж чадна, тэр нь **уйтгартай байдлыг нуухын оронд онцолно**. Эргэлт нь баталгаатай.

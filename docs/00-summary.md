## 1. Энэ судалгаа юу вэ

Чи ангиараа ширээ тойрон, хөзрөөр дүр хуваарилж, «хот унтдаг» гэж хөтлөгчтэй тоглодог мафи
тоглоомоо утасны апп болгохыг хүсэж байна. Энэ баримт бичиг бол тэр аппыг хийхэд шаардлагатай
**бүхий л судалгааг нэг дор цуглуулсан 19 бүлэг** юм.

**Хэрхэн хийсэн бэ:**

| Үзүүлэлт | Тоо |
|---|---|
| Судалгааны чиглэл | 19 |
| Ажилласан agent | 40 гаруй |
| Ашигласан token | 3.2 сая гаруй |
| Веб хайлт / эх сурвалж татсан үйлдэл | 1,500 гаруй |
| Эсрэг талын шалгагчийн илрүүлсэн алдаа | **138** |

Чиглэл бүрийг нэг agent судалсны дараа **өөр нэг agent түүнийг няцаахыг оролдсон** — тоо бүрийг
анхдагч эх сурвалжаас нь дахин шалгаж, буруу зүйлийг файл дотор нь шууд зассан. Илэрсэн алдаанууд
нь жижиг биш байсан: зохиомол wiki хуудасны нэр, байхгүй эрдэм шинжилгээний эшлэл, эсрэгээрээ
буруу ойлгосон теорем, хуучирсан үнэ. Тиймээс бүлэг бүрт «> **Баталгаажуулалт (2026-09-15)**»
гэсэн тэмдэглэгээ тааралдана — тэр нь **анхны төсөөлөл буруу байсан газар** гэсэн үг.

## 4. Хэрэгжүүлэхэд хамгийн чухал 3 томьёо

**1. Setup хүчинтэй эсэх (алдаа санал өгөх боломжийн тоо):**

```
b(N, M) = floor(N/2) − M − 1
```

`N` = нийт тоглогч, `M` = мафийн тоо. `b < 0` бол мафи эхний саналаас өмнө хожино — **татгалз**.
`b = 0` бол эхний өдрөөс LYLO (нэг алдаа = ялагдал) — **сануул**. `b = 2…3` бол ангийн тоглоомд хамгийн таатай.
Энэ томьёо нь **шөнө эхэлдэг + M ≥ T** конвенцийн дор яг зөв (N = 4…60 бүгдээр brute-force хийж шалгасан).

**2. Шөнийн үйлдлийн дараалал (хатуу priority pipeline, if-үүдийн овоо биш):**

```
1. Саатуулалт (roleblock)
2. Хамгаалалт (protect)
3. Алалт — хамгаалалттай тулган шийдэх
4. Шалгалт — анхны талыг нь харуулах
5. Бүх үхлийг НЭГЭН ЗЭРЭГ хэрэгжүүлэх
6. Ялалтын нөхцөл шалгах
```

**3. Ялалтыг хэзээ шалгах вэ:** үе шатны төгсгөлд биш, **хасалт бүрийн дараа шууд**. Гуравдагч талын
ялалтыг мафи-хот паритетийн өмнө шалгана.

## 5. Хамгийн том 3 эрсдэл

1. **Google Play-ийн төлбөр.** Android хэрэглэгчид апп доторх худалдан авалт хийх боломжгүй. Хэрэв
   чи зөвхөн Play billing дээр найдвал Android-аас орлого **тэг** болно. Веб дэлгүүрийг үндсэн зам
   гэж үз, Play billing нь ирээдүйн бонус.
2. **Сургуулийн утасны бодлого чангарч байна.** 2026 оны 9-р сараас сургуульд сошиал сүлжээ хориглосон.
   Хэрэв бүрэн утасны хориг хэрэгжвэл гол хэрэглээний тохиолдол тасарна. Хамгаалалт: офлайн, сошиал
   функцгүй дизайн, мөн хичээлийн дараах/клубын хэрэглээнд байршуулах.
   *(Энэ мэдээлэл хайлтын хэсгээс гарсан бөгөөд UNESCO-гийн PEER мэдээллийн сантай тулгаж
   баталгаажаагүй — шийдвэр гаргахын өмнө шалга.)*
3. **Зах зээлийн хэмжээ жижиг.** Хамгийн өөдрөг хувилбарт ч (22,000 DAU, ~$130k/жил) энэ бол жижиг
   студи, венчур бизнес биш. Орос хэл нэмэх нь нэгэн зэрэг хамгийн том өсөлтийн алхам **бөгөөд**
   Android төлбөрийн асуудлын шийдэл (ОХУ, Казахстан, Кыргызстан, Узбекистан бүгд Play-ийн жагсаалтад бий).

## 7. Чамаас тодруулах асуултууд

Судалгаа хэд хэдэн газар «хэрэглэгчийн анги яг яаж тоглодгийг мэдэхгүй» гэж тэмдэглэсэн. Дараагийн
тоглолтондоо эдгээрийг ажиглаад бичиж ав — эдгээр нь шууд дизайны шийдвэр болно:

1. Эмч **өөрийгөө аварч** чаддаг уу? Хэдэн удаа?
2. Хэн нэгэн хасагдахад **картыг нь нээж үзүүлдэг үү**, эсвэл нууц хэвээр үлддэг үү?
3. Санал **тэнцвэл** яадаг вэ — дахин санал уу, хэн ч хасагдахгүй юу, эсвэл хоёуланг нь хасдаг уу?
4. Эхний шөнө хүн үхдэг үү, эсвэл зөвхөн танилцдаг уу?
5. Хамгийн олондоо хэдүүлээ тоглодог вэ? Хамгийн цөөндөө?
6. Хөтлөгч нь үргэлж нэг хүн байдаг уу, эсвэл ээлжилдэг үү? (Хөтлөгч тоглож чаддаггүй нь
   ангийн хэмжээнд том алдагдал — апп үүнийг шийдэж чадна.)

- **Мөнгө олохоосоо өмнө** `11`.
- **Төлөвлөгөө гаргахдаа** `18`.

Бүлэг бүрийн эхэнд «Гол дүгнэлт» хэсэг байгаа. Бүх тоо эх сурвалжтай; баталгаажаагүй зүйлийг
«[баталгаажаагүй]» гэж тэмдэглэсэн — тэдгээрийг шийдвэрийн үндэс болгож болохгүй, өөрөө шалга.
